📞 Call Center Report Dashboard | Excel Project
Project Overview
Developed an interactive Call Center Report Dashboard using Microsoft Excel to analyze call performance, agent productivity, customer satisfaction, and operational efficiency.
Implemented data cleaning, pivot tables, formulas, and dynamic charts to track KPIs such as total calls handled, average handling time, resolution rate, and customer satisfaction score (CSAT).
Published the project on GitHub with documentation and insights to support data-driven decision-making in call center operations.

🛠 Tech Stack
The dashboard was built using the following tools and technologies:

Microsoft Excel – Main data analysis and visualization platform

Pivot Tables & Pivot Charts – For summarizing and aggregating call data

Excel Formulas – IF, VLOOKUP/XLOOKUP, COUNTIF, SUMIFS, AVERAGEIFS

Data Visualization – Bar charts, line charts, pie charts, KPI cards

Slicers & Filters – For interactive data exploration

File Format – .xlsx for development and .png for dashboard previews

Data Source

Source: Sample Call Center Dataset
The dataset contains call-level operational data across multiple agents, departments, and time periods.
It includes:

Call Date (Day, Month, Year)

Agent Name / Team

Number of Calls Handled

Average Handling Time (AHT)

Resolution Status (Resolved / Unresolved)

Customer Satisfaction Score (CSAT)

Call Type (Inbound / Outbound)

The data was cleaned and structured in Excel, and KPIs were calculated using formulas and pivot tables for performance tracking.

🚩Business Problem

Call centers generate large volumes of performance data daily. However, managers often struggle to quickly answer critical operational questions such as:
Which agents are performing best?
What is the average handling time trend?
What is the overall resolution rate?
How satisfied are customers?
Are inbound or outbound calls more efficient?
Raw spreadsheets make it difficult to extract insights quickly and monitor performance in real time.

🎯 Goal of the Dashboard

To build an interactive Excel dashboard that:
Tracks overall call center performance
Monitors agent productivity and efficiency
Analyzes customer satisfaction trends
Identifies bottlenecks in resolution time
Supports operational and staffing decisions
